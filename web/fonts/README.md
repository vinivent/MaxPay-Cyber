# Fontes

`Geist` e `Geist Mono`, da Vercel, servidas localmente para que a interface não
dependa de rede — ela é apresentada em sala de aula.

- Origem: https://github.com/vercel/geist-font
- Licença: SIL Open Font License 1.1 (texto completo em `OFL.txt`)
- Subconjunto: apenas `latin` (U+0000–00FF e afins). O português cabe inteiro
  nessa faixa; cirílico, grego, vietnamita e `latin-ext` foram removidos, o que
  reduziu os arquivos de 360 KB para 130 KB.
- Pesos: Geist 400/500/600 e Geist Mono 400/500.

Os arquivos `.woff2` vieram do Google Fonts, que serve os mesmos binários da
Vercel. Para atualizar, refaça o passo descrito em `DESIGN.md`.
